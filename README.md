# Ödev 1 dosyaları

Bu dosyalar Yapay Zeka Operatörlüğü ödevi için hazırlandı hocam. Örneklerde `llm_ops` veritabanı kullanılıyor.

## Dosyalarda neler var
- `bolum1.py`: Python ile ilgili üç soru
- `bolum2.md`: veritabanı kavramları
- `bolum3.sql`: SELECT ve WHERE soruları
- `bolum4.sql`: gruplama ve NULL soruları
- `rapor.md`: rapor taslağı
- `AI_KULLANIMI.md`: yapay zeka desteği ve kontrol adımları

## Teslim etmeden önce yapılacaklar
SQL yorumlarındaki sayılar seed dosyasındaki verilere göre tahmin edildi, burada PostgreSQL'de çalıştırılmış değiller. O yüzden sorguları kendi veritabanında çalıştırıp sonuçlara bakman gerekiyor hocam. Sonuçlar farklı çıkarsa yorumları da ona göre düzelt. Rapora kendi yaşadığın durumu ve gerçekten aldıysan hata mesajını yaz. PR bağlantısı kısmına da kendi bağlantını ekle, adını ve öğrenci numaranı kendin doldur.

Veritabanını nasıl kuracağını ders deposundaki `data/README.md` dosyasında bulabilirsin. Başlangıç verileri için `data/llm_ops.sql` dosyasını kullan.
